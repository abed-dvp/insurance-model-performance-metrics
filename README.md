# Insurance Model Performance Metrics

## Project Goal

This project studies how different machine-learning evaluation metrics tell different stories about model performance.

The same insurance dataset will be used for:

### Regression
Predict medical insurance charges.

### Classification
Predict whether a customer belongs to a cheap or expensive insurance-cost class.

## Learning Focus

- Data Preparation
- K-Nearest Neighbors
- Baseline Models
- Regression Metrics
- Classification Metrics
- Precision / Recall Trade-off
- Probability Thresholds
- ROC-AUC
- Error Analysis
